# Fonts

## Done when

For work that adds or changes glyphs:

- Each glyph added or changed is listed by name and code point, and meets the glyph standards in the docs AGENTS.md names
- Every code point rule in AGENTS.md holds (released code points are permanent public identifiers)

## Current code

For a glyph, show its current state instead of (or beside) a code snippet: the
source drawing's path, its manifest entry, its name and its code point.
