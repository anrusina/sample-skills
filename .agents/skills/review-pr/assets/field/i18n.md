# Localisation (i18n)

## Review checks

- Apply every localisation rule AGENTS.md states (where copy lives, how strings are looked up, which locale is the source).
- No user-facing text outside the translation files: labels and messages, and also accessible names, `alt` text, tooltips and titles, and page metadata. A hard-coded user-facing string is at least **High**.
- Every new key exists in the source locale; no key is used that the translation files do not define; no duplicate key; a removed key has no remaining caller.
- Text that joins translated fragments with code (concatenation, word order fixed in code) instead of one message with placeholders; plurals and dates formatted without the locale.
- A locale that is not finished must not be published where AGENTS.md says it stays hidden.
